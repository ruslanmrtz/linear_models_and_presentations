# Проект "Линейные модели и их презентация"

В проекте разбираются классические линейные модели машинного обучения - линейные и логистические регрессии, интерпретацию полученного результата, оформление исследования в виде красивого веб-сервиса (поможет библиотека Streamlit), а также оборачивание модели при помощи фреймворка FastApi.
